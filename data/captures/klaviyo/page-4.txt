Connect your agent to Klaviyo

Klaviyo's MCP server lets an agent work with the data in a Klaviyo account. Add the remote server at https://mcp.klaviyo.com/mcp to your MCP client. In Claude Code, run this command:

Add the Klaviyo MCP server to Claude Code
Copy
claude mcp add --transport http klaviyo https://mcp.klaviyo.com/mcp

Agent skills

Agent skills are step-by-step instructions that an AI coding agent such as Claude Code, Cursor or Codex follows to build on the Klaviyo API. Each one is a short SKILL.md that links to the reference and code files it needs, all in Markdown. Point your agent at the one that fits what you're building.
